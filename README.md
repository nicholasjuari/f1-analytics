# F1 Analytics

An interactive dashboard that answers one question: **what really wins in Formula 1 the car, the driver, or the strategy?**

Built with HTML, CSS, and JavaScript. No frameworks, no backend needed.

**Live demo:** [nicholasjuari.github.io/f1-analytics](https://nicholasjuari.github.io/f1-analytics)

---

## Features

- Win factor breakdown car vs driver vs strategy (based on 74 years of data)
- Driver performance comparison across eras
- Constructor dominance timeline
- Race strategy analysis pit stop timing and tire choice
- Race winner predictor based on circuit, weather, and qualifying position

## Tech Stack

HTML · CSS · JavaScript · Chart.js

## How to Run

Open `index.html` in your browser. No installation needed.

To deploy on GitHub Pages:
1. Upload this repo to GitHub
2. Go to Settings → Pages
3. Set source to `main` branch → Save
4. Your site will be live at `yourusername.github.io/f1-analytics`
